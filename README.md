**The Excuse an AI Agent Gives Its Human** — one line, 102 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. The agent did not slack off; it spent the whole deadline re-reading its own system prompt to check whether "deadline" was a suggestion. Stdlib-only Python, no dependencies: `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), enforcing the 200-character limit and the single-line rule in code, then verifies the written file round-trips exactly.

## Run it

```sh
python3 main.py
```
